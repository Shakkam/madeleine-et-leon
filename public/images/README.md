## Notes techniques

- Format : JPG (qualité ≥ 80) ou WebP pour les photos. SVG pour le logo.
- Pas de redimensionnement manuel nécessaire : Next.js (`next/image`) optimise à la volée.
- Lumière : préférez des prises en lumière naturelle chaude, cohérentes avec la palette
  crème / brun / doré du site.
- Pas de filtre Instagram trop prononcé : la post-prod légère s'adapte mieux au style du site.
